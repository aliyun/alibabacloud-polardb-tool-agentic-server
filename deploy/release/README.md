# Deployment bundle

This directory is included in the versioned deployment bundle. Verify
`SHA256SUMS` and GitHub attestations before extracting or importing artifacts.

The bundle contains Compose definitions, the Helm Chart, deployment helpers,
licenses, and the English and Simplified Chinese deployment guides. It never
contains a metadata database URL, root encryption key, bootstrap token, or
other deployment secret.

Start with `docs/en/deployment/offline-installation.md` or
`docs/zh-cn/deployment/offline-installation.md`.
