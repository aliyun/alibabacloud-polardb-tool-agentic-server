# 用户与部门

[English](../../en/administration/users-and-departments.md)

管理员在 Web 控制台管理人类身份和组织访问。Agent 身份相互独立，在
**Agents** 中管理。

## 用户

创建用户时设置唯一用户名、显示名称、角色、状态和可选部门。内置用户使用
密码；SSO 用户按已配置的身份声明匹配。管理员可以启用、停用、重置或删除
用户；停用会阻止新的认证和授权。

用户实例访问需要选择已注册实例、有效的 `direct_access` 凭证、
`readonly` 或 `readwrite` 权限和显式能力。只授予 MySQL 账号允许的数据库和
操作；PAS 不会提升后端权限。

## 部门

部门用于组织用户，并可引用一个已经注册的 `multitenant` 实例。实例注册和
凭证轮换仍在 **Instances** 中完成。部门成员关系不会复制密码，也不会创建
新的物理实例。

部门供应通过所选后端创建逻辑租户资源。删除部门或绑定属于管理操作，执行前
应检查自有资源和清理状态。

## 安全管理

管理员账号和数据库账号应相互独立；人员变动后复查绑定，并在角色、状态、
部门、凭证或实例访问变更后检查 Audit Logs。
