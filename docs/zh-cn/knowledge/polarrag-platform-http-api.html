PolarRAG 平台 HTTP API

完整字段、分页、错误码和全部端点请参阅同目录的 Markdown 文档 或目标 PAS 的 /openapi.json。

认证边界：管理员先在“外部应用”页面注册调用方服务并领取一次性 Client Secret、Resource、Scope 和请求示例。外部应用可通过 PAS 的 /token 或 /api/v1/external-auth/token 执行标准 Token Exchange。PAS 只签发 Access Token，不签发 Refresh Token；除非单独启用直连兼容模式，否则不会直接接受飞书 user_access_token。

一、授权前提

  • PAS Token 的 aud 为 <PAS base URL>/api/v1；
  • scope 包含 polarrag；
  • Token 代表一个 PAS 用户和有效 Agent 上下文；PAS 在每次请求中复核用户仍有该 Agent 访问权。

二、管理员准备

管理员先创建 Agent、授予 PolarRAG 资源，并将目标用户或企业用户组绑定给 Agent。使用 Token Exchange 时，还需配置外部 Token 信任并注册外部应用。需要查询现有对象时可使用：

GET /api/agents
GET /api/identity-sources
GET /api/identity-sources/<identity_source_id>/directory?entry_type=all&limit=100
GET /api/identity-sources/spaces

将 PAS 用户绑定给 Agent：

POST /api/agents/<agent_id>/user-assignments
Authorization: Bearer <admin-token>
Content-Type: application/json

{"user_id":"<pas-user-id>"}

三、使用 PAS Token 访问知识库

Token Exchange 签发 PAS 用户 Token → 查询可见知识库 → 使用知识库、Space/KB 或文档路径检索和查看文档。
GET /api/v1/knowledge-bases?limit=50
Authorization: Bearer <pas-user-access-token>
POST /api/v1/knowledge-bases/<knowledge_resource_id>/search
Authorization: Bearer <pas-user-access-token>
Content-Type: application/json

{"query":"退款流程","search_mode":"balanced","top_k":10,"reranker":false}
POST /api/v1/spaces/<space_id>/knowledge-bases/<kb_id>/search
Authorization: Bearer <pas-user-access-token>
Content-Type: application/json

{"query":"退款流程","search_mode":"balanced","top_k":10,"reranker":false}
GET /api/v1/knowledge-bases/<knowledge_resource_id>/documents?limit=20
GET /api/v1/spaces/<space_id>/knowledge-bases/<kb_id>/documents?limit=20

知识库和文档结果始终受 PAS 用户授权、Agent 资源范围及 PolarRAG 文档 ACL 共同约束。
